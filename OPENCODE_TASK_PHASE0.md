# B5-ARCADE: Фаза 0 — каркас игры (Vite + TypeScript + Phaser 3)

Проект: браузерная аркада-клон Asteroids во вселенной «Вавилон 5».
Игрок пилотирует **SA-23 Starfury** (Звёздная ярость Земного Альянса) и расчищает астероидное поле.

Справка: SA-23 «Thunderbolt» Starfury — истребитель Земного Альянса из B5: 4 плазменные пушки на крыльях,
инерционный полёт, в сериале маневрирует в плоскости (отлично ложится на 2D asteroids-геймплей).
Внешний вид: центральный короткий фюзеляж-кокпит, четыре расходящихся крыла (X-образная компоновка), тёмный металлик с жёлто-чёрной окраской Earthforce.

## Требуемый результат фазы 0

Рабочий игровой каркас, в котором:
1. Vite + TypeScript проект собирается (`npm run build` проходит без ошибок, `npx tsc --noEmit` чисто)
2. Phaser 3 (актуальная 3.x) подключён и запускается
3. Есть сцены: BootScene (генерация/загрузка ассетов) → MainScene
4. В MainScene:
   - Starfury (спрайт можно нарисовать программно в Canvas-текстуру в BootScene — X-образный силуэт с 4 крыльями, тёмно-серый металлик, жёлтые полосы Earthforce)
   - Инерционный полёт: стрелки/WASD — вращение (Left/Right), тяга (Up), стрельба (Space)
   - Пули летят по направлению носа, за экран заворачиваются (wrap)
   - Астероиды: 3 размера (large→medium→small), при попадании разламываются на 2 меньших, малые уничтожаются; формы — процедурные многоугольники (Canvas-генерация)
   - Wrap по всем краям экрана для корабля, пуль, астероидов
   - HUD: очки (large=20, medium=50, small=100), жизни (3), уровень
   - Столкновение корабля с астероидом: -1 жизнь, респаун в центре с 2-сек неуязвимостью (мигание)
   - Game over → рестарт по Enter
5. Разрешение: 1280x720, фон — звёздное небо (процедурная генерация: 2-3 слоя звёзд с параллаксом — можно статичные слои разной яркости)

## Структура

```
b5-arcade/
├── index.html
├── package.json
├── tsconfig.json
├── vite.config.ts
└── src/
    ├── main.ts            # конфиг Phaser, запуск BootScene
    ├── scenes/
    │   ├── BootScene.ts   # генерация текстур (корабль, астероиды, пуля, звёзды)
    │   ├── MainScene.ts
    │   └── UIScene.ts     # HUD поверх (optional, можно HUD в MainScene)
    ├── entities/
    │   ├── Starfury.ts
    │   ├── Asteroid.ts
    │   └── Bullet.ts
    └── utils/
        └── textures.ts    # процедурная генерация Canvas-текстур
```

Стиль кода: строгий TypeScript (strict: true), без any, классы для сущностей, никаких избыточных абстракций — это аркада.

## Верификация (ОБЯЗАТЕЛЬНО выполнить и добиться успеха)

1. `npm install`
2. `npx tsc --noEmit` — без ошибок
3. `npm run build` — успешная сборка
4. `npm run preview` + краткая проверка, что сервер отдаёт index.html (curl)
