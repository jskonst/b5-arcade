## Статус

Идея / подготовка. Стек и архитектура — на обсуждении (см. обсуждения).

## Идеи

- Классический asteroid-геймплей: инерция, разлом астероидов, экранные границы
- Скин вселенной B5: White Star, Shadow-астероиды/обломки, звёздное небо с гиперпространственным порталом
- Пасхалка-связка с основной игрой [b5-game](https://github.com/jskonst/b5-game) (RPG + LLM)
