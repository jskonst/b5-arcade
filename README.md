# b5-arcade

Аркадная мини-игра во вселенной «Вавилон 5»: клон Asteroids.
Пилот — **SA-23 Aurora Starfury** (не White Star): четыре мотогондолы крестом,
кокпит в перекрестье, серый металл и жёлто-чёрные полосы Earthforce.
Спрайт — оригинальная процедурная модель (своё, без сторонних картинок).

Настроение — фанатский [B5: Sector 87](http://mods.firstones.com/sector87/).
Стек: TypeScript + Phaser 3 + Vite (в репозитории Babylon.js нет).

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка типов: `npm run build`.
Прод-превью: `npm run preview` (base `/b5-arcade/`, как на GitHub Pages).

Сенсорный оверлей сам включается на телефонах, планшетах и узком окне.
На десктопе его можно открыть адресом `?touch=1` и спрятать `?touch=0`.

## Управление

Бочка — оборот вокруг продольной оси (~0.56 с). Пока она играется, столкновения не снимают жизнь.
Сразу повторить бочку нельзя: короткая пауза после оборота, чтобы неуязвимость не была постоянной.

### Клавиатура

| Действие | Клавиши |
| --- | --- |
| Поворот | ← → или A / D |
| Тяга вперёд | ↑ или W |
| Задний ход | ↓ или S |
| Огонь | Space (удерживать) |
| Бочка влево | Q, Shift+←, Shift+A, или двойной тап ← / A |
| Бочка вправо | E, Shift+→, Shift+D, или двойной тап → / D |
| Рестарт | Enter |

Двойной тап поворота — как бочка в Star Fox: два коротких нажатия в ту же сторону.

### Сенсор

- Стик слева: вверх — вперёд, вниз — задний ход, влево/вправо — поворот.
- Резкий двойной флик стика вбок (между рывками вернуть стик к центру) — бочка.
- Двойной свайп влево/вправо по полю — бочка.
- Двойной тап по левому или правому краю поля — бочка.
- Кнопки ⟲ и ⟳ — бочка влево и вправо.
- FIRE справа — огонь, пока палец удерживается.
- На game over — тап или Enter.

Клавиатура по-прежнему работает, когда оверлей на экране.

## Эффекты

Пиксельные эффекты взяты из [pixelfx](https://github.com/patch-gg/pixelfx) (MIT, © Patch, Hugo Duprez), выгружены его инструментом `tools/render.mjs --sheet` в спрайт-листы и лежат в `public/fx/` (лицензия — `public/fx/NOTICE.md`). Проигрываются как анимации Phaser с nearest-фильтрацией (`src/fx/pixelfx.ts`):

- мелкий астероид — `small-explosion`, средний/крупный — `plasma-explosion`;
- попадание пули — `hit-spark`, вспышка выстрела — `muzzle-smg`;
- гибель корабля — `implosion`;
- неуязвимость во время бочки — щит `divine-shield` в синей палитре.

## Спрайт истребителя

Игровой корабль рисуется листом бочки `public/ships/fighter-roll.png`: крен переключает кадры, дула и сопла берутся из `fighter-anchors.json`. Это **своя** низкополигональная модель, не Starfury и не чужой корабль.
Её целиком собирает `tools/blender/render_fighter.py` из примитивов: вытянутый корпус, фонарь, четыре пилона крестом, на каждом короткая мотогондола, две носовые пушки.
Серый корпус без полос и опознавательных знаков. Отдельного файла модели в репозитории нет, скачанных мешей нет: геометрия — часть скрипта и лежит в репозитории на тех же условиях, что и остальной код.

- `public/ships/fighter-roll.png` — 16 кадров 256×256 одной полосой, полный оборот вокруг продольной оси (шаг 22.5°). Нос вправо (+X кадра), камера сверху, фон прозрачный, масштаб во всех кадрах один.
- `public/ships/fighter-roll.json` — `frameWidth` / `frameHeight` для `this.load.spritesheet`.
- `public/ships/fighter-anchors.json` — пиксели дул и сопел в кадре 0 (левый верх). Считаются проекцией пустышек через `world_to_camera_view`, не вручную. В нулевом крене верхняя и нижняя гондолы одного борта попадают в одну точку экрана; ближе к камере та, у которой `viewZ` меньше.

Перерендер (из корня репозитория, нужен Blender 4.2+, проверялось на 4.5.16 LTS):

```bash
blender -b -P tools/blender/render_fighter.py -- --output public/ships --size 256 --frames 16
```

Своя модель вместо процедурной. Нос по +X, спина по +Z, ось крена — мировая ось X через origin, поза без крена. Скрипт делает append (локальная копия на время рендера). Без `--collection` забирает все объекты файла, камеры и источники света пропускает. Без `--anchors` ищет объекты, чьи имена начинаются с `gun` и `nozzle`.

```bash
blender -b -P tools/blender/render_fighter.py -- \
  --model path/to/fighter.blend \
  --collection Fighter \
  --anchors gun:muzzle_l,gun:muzzle_r,nozzle:port,nozzle:starboard \
  --output public/ships
```

Чужие модели франшиз сюда не класть: скрипт их отрендерит, но в репозиторий они не входят.
