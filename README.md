# b5-arcade

Аркадная мини-игра во вселенной «Вавилон 5»: клон Asteroids.
Пилот — **SA-23 Aurora Starfury** (не White Star): четыре мотогондолы крестом,
кокпит в перекрестье, серый металл и жёлто-чёрные полосы Earthforce.
Спрайт — оригинальная процедурная модель (своё, без сторонних картинок).

Настроение — фанатский [B5: Sector 87](http://mods.firstones.com/sector87/).
Стек: TypeScript + Phaser 3 + Vite (в репозитории Babylon.js нет).

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка типов: `npm run build`.
Прод-превью: `npm run preview` (base `/b5-arcade/`, как на GitHub Pages).

Сенсорный оверлей сам включается на телефонах, планшетах и узком окне.
На десктопе его можно открыть адресом `?touch=1` и спрятать `?touch=0`.

## Управление

Бочка — оборот вокруг продольной оси (~0.56 с). Пока она играется, столкновения не снимают жизнь.
Сразу повторить бочку нельзя: короткая пауза после оборота, чтобы неуязвимость не была постоянной.

### Клавиатура

| Действие | Клавиши |
| --- | --- |
| Поворот | ← → или A / D |
| Тяга вперёд | ↑ или W |
| Задний ход | ↓ или S |
| Огонь | Space (удерживать) |
| Бочка влево | Q, Shift+←, Shift+A, или двойной тап ← / A |
| Бочка вправо | E, Shift+→, Shift+D, или двойной тап → / D |
| Рестарт | Enter |

Двойной тап поворота — как бочка в Star Fox: два коротких нажатия в ту же сторону.

### Сенсор

- Стик слева: вверх — вперёд, вниз — задний ход, влево/вправо — поворот.
- Резкий двойной флик стика вбок (между рывками вернуть стик к центру) — бочка.
- Двойной свайп влево/вправо по полю — бочка.
- Двойной тап по левому или правому краю поля — бочка.
- Кнопки ⟲ и ⟳ — бочка влево и вправо.
- FIRE справа — огонь, пока палец удерживается.
- На game over — тап или Enter.

Клавиатура по-прежнему работает, когда оверлей на экране.
